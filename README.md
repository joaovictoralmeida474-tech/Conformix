# Integraxx

## URL de producao (Vercel)

1. Renomeie o projeto na Vercel para **`integraxx`** (Settings → General → Project Name) para obter `https://integraxx.vercel.app`.
2. Faca **deploy** deste repositorio.
3. No **Supabase** → **Authentication** → **URL Configuration**, use a URL real do deploy (ex.: `https://integraxx.vercel.app`).

O backend aceita automaticamente o dominio atual da Vercel em CORS.
